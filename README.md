# BuddySPair

BuddySPair is a **real-time matrimony application** designed to help users find their ideal partner. Built with modern web technologies, it provides features like messaging, notifications, and profile matching, making the process interactive and seamless.

---

## 🚀 Features

- **User Authentication & Authorization**
  - Secure login and signup using **Passport.js** and **JWT**.
- **Matrimony Profiles**
  - Create, view, and manage user profiles.
  - Search and filter profiles based on preferences.
- **Real-time Messaging**
  - Send and receive messages instantly using **Socket.io**.
- **Notifications**
  - Real-time notifications for messages, requests, and updates.
- **Sorting & Filtering**
  - Sort and filter profiles based on age, location, interests, and more.
- **OTP Verification**
  - Phone number verification using **Twilio**.

---

## 🛠️ Technology Stack

- **Frontend:** React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB, Mongoose  
- **Authentication:** Passport.js, JWT  
- **Real-time Communication:** Socket.io  
- **SMS/OTP Verification:** Twilio
